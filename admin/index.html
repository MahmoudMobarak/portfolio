Tutorial — Editing Everything & Committing to GitHub

How to use this panel for every section, and how to get your changes onto GitHub Pages.

  1. Pick a tab on the left (Profile, Report Cards, Certificates, Projects, Extracurriculars, Skills).
  2. Edit the fields — every change is tracked in memory instantly.
  3. Click Save All Changes (top right). This writes portfolio-data.json AND regenerates index.html automatically.
  4. Click Preview Portfolio (top right) to check the live site, then hard-refresh with Ctrl+Shift+R.

Nothing is public until you commit & push to GitHub — see step 6.

  • Add a new grade/year: Academic Report Cards tab → "Year Tabs" card → type the year (e.g. 11) → Add Year → + Add New Report Card → set its Academic Year to 11.
  • Upload the report card image (JPG/PNG) and the PDF separately — the image shows on the site, the PDF powers the "Download PDF" link.
  • Remove a year: click the × on its chip in the Year Tabs card. Report cards of that year keep their label but lose the tab.
  • Use the Filter by Year dropdown to see only one year's cards while editing.
  • New category: just type a new category name on any certificate (e.g. Sports) — the website groups categories automatically.
  • Each certificate has title, description, tags (glass chips on the photo), an optional link (verification/PDF), and the photo upload.
  • Remove: the Delete button on the card. Add: the "+ Add New Certificate" button.
  • On the site, hover a certificate to expand it and click it to open the big reader view with ←/→ arrows.
  • Projects: title, card title, description, feature points (one per line), tech tags, screenshot, optional live URL + GitHub URL, and a checkbox to show/hide the "Check out" button.
  • Extracurriculars: title, lead line (the short italic hook), description, tags (chips on the photo), photo.
  • Skills: three categories of chips — type in the box, press Add Skill. Click × on a chip to remove it.
  • Every list can be added to, edited, or deleted — the site regenerates on save.
  • Photos/ — project screenshots and activity photos
  • Certificate/ — certificate scans
  • Report Cards/Photos/ — report card images
  • Report Cards/PDF/ — report card PDFs

The upload buttons inside each editor put files in the right folder automatically — prefer them over manual file management.

One-click way: after saving, press Push to GitHub (top right). It runs the equivalent of git add . → git commit → git push for you. The first time ever, push from a terminal instead (see below) so Git knows who you are.

Terminal way (full control):

git add . git commit -m "Update portfolio content" git push

First-time setup (once per computer):

git config --global user.name "Your Name" git config --global user.email "you@example.com" git remote add origin https://github.com/USERNAME/REPO.git git push -u origin main

GitHub Pages: in your repo → Settings → Pages → Source: Deploy from a branch → branch main, folder / (root) → Save. Your site goes live at https://USERNAME.github.io/REPO/. The admin/ folder and portfolio-data.json are excluded from publishing via .gitignore/.nojekyll — the live site only needs index.html, CSS, JS and images.

Full walkthrough: see COMMIT_GUIDE.md in the project root.
